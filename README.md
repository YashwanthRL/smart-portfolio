## ✨ Features

- 🎨 **Stunning Particle Animations** - Interactive background with mouse-responsive particles
- 🌓 **Dynamic Theme Switcher** - Toggle between dark and light modes with smooth transitions
- 💻 **GitHub API Integration** - Live display of your repositories and contribution activity
- ⌨️ **Typing Animation** - Professional typing effect showcasing your roles
- 📊 **Animated Statistics** - Smooth counting animations for achievements
- 🎯 **Project Filtering** - Category-based project showcase
- 📱 **Fully Responsive** - Optimized for all devices (mobile, tablet, desktop)
- 🎭 **Custom Cursor** - Unique cursor effects for enhanced UX
- 🕒 **Interactive Timeline** - Visual journey of your experience
- 📈 **Skills Visualization** - Animated progress bars with hover effects
- 📬 **Contact Form** - Validated contact form with smooth interactions
- ⚡ **Performance Optimized** - Lazy loading, smooth scrolling, and efficient animations

## 🛠️ Technologies Used

### Core Technologies
- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Grid, Flexbox, Animations
- **JavaScript (ES6+)** - Modern JS features

### Web APIs Used
- Canvas API (Particle System)
- Intersection Observer API
- Fetch API (GitHub Integration)
- Local Storage API
- Web Animation API

### External Libraries
- Font Awesome (Icons)
- Google Fonts (Typography)
